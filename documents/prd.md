# PRD
## Project Name
PictureGPS-to-MapOnline
## Project Type
web-app
## Goal
เป็นโปรแกรมที่ทำงาน จะทำโดยการ upload ภาพที่มี GPS โปรแกรมจะอ่าน meta data ของรูปภาพและมีการแสดงพิกัดบน map และบอกค่าต่างในรูปภาพ เท่าที่สามารถทำได้ถ้ามีการ upload หลายๆ ภาพ จะทำการเช็คเวลาที่ถ่ายและทำเป็นเส้น Routing ให้และมีบอก label ว่ารูปไหนเกิดก่อน ให้ใส่เลข 1 รูปที่ถ่ายเวลาถัดไปก็เป็นเลข 2 และสร้าง เส้น Routing บน MAP 
## Target Users
ผู้ที่จากตรวจสอบรูปภาพว่าถ่ายที่ไหน Timeline เป็นอย่างไร
## Core Features
- 1. upload รูปภาพได้หลายๆรูป
- 2. หาพิกัด GPS จากรูปภาพ
- 3. แสดงบน MAP
- 4. ทำ label บนแผนที่
- 5. สร้างเส้น Routing จาก label บน Map
- 6. บันทึกเป็นรูปได้
- 7. อ่าน Meta Data ของรูปได้
- 8. รองรับรูปภาพหลาย Format
## User Flow
เริ่มแรกโปรแกรมจะให้ Upload รูป ซึ่งสามารถ Upload ได้ทีละหลายๆรูป จะทำการตรวจสอบ Meta Data และ GPS ของรูปภาพ และมีการแสดงพิกัดบน map และบอกค่าต่างในรูปภาพ เท่าที่สามารถทำได้ถ้ามีการ upload หลายๆ ภาพ จะทำการเช็คเวลาที่ถ่ายและทำเป็นเส้น Routing ให้และมีบอก label ว่ารูปไหนเกิดก่อน ให้ใส่เลข 1 รูปที่ถ่ายเวลาถัดไปก็เป็นเลข 2 และสร้าง เส้น Routing บน MAP 
## Success Criteria
มีการแสดงพิกัดบน map และบอกค่าต่างในรูปภาพ เท่าที่สามารถทำได้ถ้ามีการ upload หลายๆ ภาพ จะทำการเช็คเวลาที่ถ่ายและทำเป็นเส้น Routing ให้และมีบอก label ว่ารูปไหนเกิดก่อน ให้ใส่เลข 1 รูปที่ถ่ายเวลาถัดไปก็เป็นเลข 2 และสร้าง เส้น Routing บน MAP 
## Constraints
ไม่ต้องมี Database, ไม่ต้องมีระบบ login สามารถ Deploy บน Free Host ได้เช่น Netlify, Github
